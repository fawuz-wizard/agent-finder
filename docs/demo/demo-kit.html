Agent Finder · demo kit

Two Android apps, one codebase. Everything runs on the phone: no server, no Wi‑Fi needed after install.

1. Install (scan with the phone's camera)

Download page Both apps, with these notes. Start here.
Agent Finder The customer's side (agent-finder.apk)
Agent App Agents and aggregators (agent-app.apk)
  1. Scan, tap the .apk, then Download, then Open.
  2. First time only: Android asks to allow installs from this source. Allow it, then Install.
  3. Install both apps. They sit side by side on the home screen.

2. What to show

AAgent Finder — the customer

  1. Open the app: the Orange Money home. Tap the Agent Finder banner.
  2. If the phone's location is off, the app asks to turn it on. Say yes.
  3. Keep Cash out, tap 2,000, then Find agent.
  4. Point out the two lists: Recommended (can likely handle the amount) and Nearest (by distance, with honest status pills).
  5. Tap Get details on a shop, then Get Directions: the map and the walk, then I'm going there.
  6. Back on the home screen: the shop appears under Recent. How availability works explains the estimate in plain words.

BAgent App — agents and aggregators

PIN is 1234 for every demo account.

  1. Choose Agent, code 024 (Fatmata's Shop), PIN 1234.
  2. Home: today's signal. Availability: open/closed and what the shop can handle, in words, never figures. Float: ask the aggregator for more. Hours: the weekly grid.
  3. Sign out. Choose Aggregator, number kissy, PIN 1234.
  4. Overview: the five signals. Agents: the register, with who is on the map and whose pin waits for confirmation. Float: approve a request. Attention: who needs a call.
  5. Other agent codes to try: 031, 009, 017, 038.

3. If asked

  • Where does the data come from? This build carries a seeded demo network of shops around Lumley. The pilot build reads Orange's own aggregator and agent file (95 agents, 2 aggregators, imported and cleaned) and places a shop on the map only once its aggregator confirms the pin.
  • Why "can likely handle"? The app never shows balances. It estimates from recent transaction activity and says so; the customer confirms at the shop.
  • What is left? Hosting (API server and web app), a Google Maps key for the live map, and the venue agents' pins. The code for all of it is built and tested; it needs accounts and keys.

The ribbon at the top of every screen says "Demo build". The link behind each QR code always serves the newest build, so there is nothing to reprint.
