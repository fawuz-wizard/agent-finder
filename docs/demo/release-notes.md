Two apps, one codebase. Install both on an Android phone; nothing else is needed.

| App | What it shows | Download |
|---|---|---|
| **Agent Finder** | The customer's side, inside the Orange Money app: find a nearby agent who can likely handle a cash out or cash in right now | `agent-finder.apk` below |
| **Agent App** | The agent's and the aggregator's side: availability, float, hours, the agent register, the attention list | `agent-app.apk` below |

**Install.** Tap the `.apk`, then *Download*, then *Open*. The first time, Android asks to allow installs from this source: allow it, then tap *Install*.

**Demo sign-in (Agent App).** PIN `1234` for everyone. Agent code `024` (Fatmata's Shop), `031`, `009`, `017` or `038`. Aggregator: `kissy`.

**Customer flow (Agent Finder).** Open the app, tap the *Agent Finder* banner, keep *Cash out*, tap *2,000*, then *Find agent*. Open a shop with *Get details*, then *Get Directions*. If the phone's location is off, the app asks to turn it on.

The demo build says so on a ribbon at the top of every screen. It carries a seeded demo network of shops around Lumley; no personal data, no real transactions.
