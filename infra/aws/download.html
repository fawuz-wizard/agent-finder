How to install

  1. Tap a download button and open the file when it finishes.
  2. If Android asks, allow installing apps from your browser.
  3. If an older Agent Finder is on the phone and the install fails, remove the old one first.

iPhone: open the web version in Safari instead: agents at the Agent App, customers at Agent Finder.
